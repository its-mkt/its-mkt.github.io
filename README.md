# its.itket.com — 아이티스 포털

`https://its.itket.com/` 첫 화면. 아이티스의 대시보드·홈페이지·사내 도구 링크를 모았다 (회사 공용).
GitHub 조직 대표 Pages 사이트(`its-mkt/its-mkt.github.io`)라, 자체 도메인이 없는 저장소는 자동으로 `its.itket.com/<저장소 이름>/` 에서 열린다.

| 경로 | 저장소 |
|---|---|
| `/` | 이 저장소 (포털) |
| `/ad-insight/` | [its-mkt/ad-insight](https://github.com/its-mkt/ad-insight) — 광고 인사이트 |
| `/analytics/` | [its-mkt/analytics](https://github.com/its-mkt/analytics) — 사이트 분석 |
| `/on-core-renewal/` | [its-mkt/on-core-renewal](https://github.com/its-mkt/on-core-renewal) — 온코어 리뉴얼 시안 |

## 링크 추가

`links.js` 에 한 줄 추가하고 `main` 에 push 하면 1분 안에 반영된다. 공개 페이지라 관리자 주소·내부 문서는 넣지 않는다.

새 서비스: 저장소를 만들고 Pages 를 켠 뒤(사용자 도메인 비움) `links.js` 에 추가. 빌드 도구라면 base 를 `/<저장소 이름>/` 로 둔다.

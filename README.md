# its-mkt.github.io

공용 주소 `https://its.itket.com/` 의 첫 화면(도구 목록). GitHub 조직 대표 Pages 사이트라, 자체 도메인이 없는 저장소는 자동으로 `its.itket.com/<저장소 이름>/` 에서 열린다.

| 경로 | 저장소 |
|---|---|
| `/ad-insight/` | [its-mkt/ad-insight](https://github.com/its-mkt/ad-insight) |
| `/analytics/` | [its-mkt/analytics](https://github.com/its-mkt/analytics) |

새 도구를 추가할 때: 저장소를 만들고 Pages 를 켠 뒤(사용자 도메인 비움) 이 목록과 index.html 에 한 줄 추가한다. 빌드 도구라면 base 를 `/<저장소 이름>/` 로 둔다.
